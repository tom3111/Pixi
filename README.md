# Pixi

**Beyond the screen.**

Pixi is a personal, non-commercial mobile app that helps people decide what to watch tonight.

## Features

- **Vertical feed**: full-screen movie posters with synopsis and trailers. Swipe up for the next title.
- **Swipe mode**: swipe right to save a title, left to skip it.
- **Quiz** (planned): a short mood-based quiz, solo or with a group.
- **Guess my pick** (planned): yes/no questions that narrow down the catalog.
- **My list** (planned): saved titles and updates on followed shows.
- **Friends** (planned): see what people you trust are watching.
- **Where to watch** (planned): streaming availability by country.

## Built with

- React Native and Expo
- Expo Router
